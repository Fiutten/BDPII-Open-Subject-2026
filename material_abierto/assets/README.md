# Recursos de licencia

`cc_by_sa_4_0.png` combina el pictograma oficial CC BY-SA distribuido con el paquete `doclicense` de TeX Live y la indicación textual de la versión 4.0.

El distintivo se utiliza únicamente para identificar la licencia de los materiales. Los nombres y logotipos de Creative Commons son marcas de sus titulares y no quedan cubiertos por la licencia de esta obra. Véanse las [políticas de Creative Commons](https://creativecommons.org/policies/).
