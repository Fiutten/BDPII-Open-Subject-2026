# Organización temática de prácticas

Las versiones PDF de los enunciados y ejercicios se organizan por tema:

- `Tema_02_Streaming_Tiempo_Real`: enunciados de Kafka y Spark Structured Streaming.
- `Tema_04_IA_Generativa`: ejercicios de las tres sesiones de IA generativa.
- `Tema_05_Proyecto_Integrado`: referencia al ejercicio de seguimiento Text-to-SQL, cuyo paquete ejecutable se conserva en `../programas/Tema_05_Proyecto_Integrado/`.
- `Proyecto_Final`: enunciado de la actividad evaluable final, que integra el temario completo y no se clasifica como contenido del tema 5.

Las fuentes editables DOCX se mantienen separadas en `../fuentes/practica/`.
