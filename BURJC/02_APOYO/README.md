# Documentación de apoyo para BURJC

Esta carpeta contendrá la información necesaria para cumplimentar el depósito: instrucciones, descripción, palabras clave, licencias, metadatos de DSpace, manifiesto de ficheros y sumas SHA-256.

Su contenido sirve como apoyo administrativo y **no se adjunta al depósito**, salvo que la convocatoria indique expresamente lo contrario.
