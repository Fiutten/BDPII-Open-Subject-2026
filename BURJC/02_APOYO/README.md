# Documentación de apoyo para BURJC

Esta carpeta contiene la información necesaria para cumplimentar el depósito: instrucciones, descripción, palabras clave, licencias, metadatos de DSpace, justificación de criterios, borradores de declaraciones, manifiesto de ficheros y sumas SHA-256.

Su contenido sirve como apoyo administrativo y **no se adjunta al depósito**, salvo que la convocatoria indique expresamente lo contrario.
